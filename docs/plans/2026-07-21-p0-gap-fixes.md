# P0 修复: Shell, 斜杠命令, 历史消息加载

**目标:** 修复 3 个 P0 UI 功能缺口 — 让用户可见的功能真正可用。

## 修复 1: Shell 模式 (`!` 前缀) Wiring

**现状:** `chatStore.ts:189-195` 的 `shellCommand()` 方法存在但从未被 UI 调用。

**修改:**
1. `chatStore.ts`: 删除 `shellCommand` / `writeCommand` 的 `finally { set({ waiting: false }) }` — 等待状态由 SSE 事件管理，不应在 RPC 返回后覆盖
2. `ChatScreen.tsx` `handleSend`:
   - 检查 `text.startsWith('!')` → 调用 `shellCommand`
   - 否则走原有 `message.send`

## 修复 2: 斜杠命令 (`/` 前缀) Wiring

**现状:** `chatStore.ts:197-203` 的 `writeCommand()` 方法存在但从未被 UI 调用。

**修改:**
1. `ChatScreen.tsx` `handleSend`:
   - 检查 `text.startsWith('/')` → 调用 `writeCommand`
   - 注意: `!` 优先级高于 `/`

## 修复 3: 切换会话后加载历史消息

**现状:** `chatStore.ts:61-68` `setActiveSession` 直接清空 `messages: []`，历史消息丢失。

**修改:**
1. `ChatScreen.tsx` 增加 `useEffect`:
   - 当 `activeSessionId` 变化时
   - 如果有 `client`，调用 `sessionStore.getSessionMessages(id, clientCall)`
   - 将返回的消息追加到 `chatStore`
